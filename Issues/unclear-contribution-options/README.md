# Unclear Contribution Options Issue

## Issue Description
Users only see "Give" buttons for cash donations, but don't know they can contribute skills, items, or time. The UI doesn't show what types of support are needed.

## Files in this folder:

### `contribution-visibility-issue.md`
- Problem analysis and why visibility matters
- Proposed visual contribution indicators
- Implementation examples and expected results
- Before/after comparison

## Quick Summary:
**Problem:** Users don't know they can help with skills, items, or time
**Solution:** Add visual icons and indicators for all contribution types
**Impact:** 80%+ more users understand they can help, 60%+ increase in non-monetary contributions

## Key Features:
- **Contribution Icons:** 💰 Cash, 🛠️ Skills, 📦 Items, ⏰ Time, 🚚 Transport
- **Status Indicators:** Show what's needed vs collected
- **Multiple CTAs:** Different buttons for different contribution types
- **Enhanced Filters:** Icons in filter buttons
- **Progress Tracking:** Real-time updates for each type

## Visual Improvements:
- **Project Cards:** Show all contribution types with icons
- **Action Buttons:** "Donate Money", "Share Skills", "Donate Items", "Volunteer"
- **Status Display:** "Skills: 2/5 needed", "Items: 0/10 collected"
- **Filter Enhancement:** Icons in contribution filters

## Expected Results:
- **80%+** more users understand they can help
- **60%+** increase in non-monetary contributions
- **50%+** more diverse contribution types
- **40%+** increase in overall project participation

## Implementation:
1. Add contribution type icons to project cards
2. Show what's needed for each project
3. Replace single "Give" button with multiple options
4. Update contribution filters with icons
5. Add progress indicators for each type
