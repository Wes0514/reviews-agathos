# ISSUE: Unclear Contribution Options - Users Don't Know They Can Help

## Problem Summary
Users only see "Give" buttons for cash donations, but don't know they can contribute skills, items, or time. The UI doesn't show what types of support are needed.

**Current State:** Only "Give" button visible  
**Impact:** Users miss opportunities to help in non-monetary ways  
**Priority:** HIGH - Critical for user engagement and project success

## Why This Matters

### **Current Problem:**
- Users only see "Cash 0%" and "Give" button
- No indication of other contribution types
- Skills, items, and time contributions are hidden
- Users think they can only donate money

### **Result:**
- Users who can't donate money don't participate
- Projects miss out on valuable skills and items
- Lower overall engagement
- Missed opportunities for community building

## Proposed Solution: Visual Contribution Indicators

### **1. Contribution Type Icons**
**Add icons to show what's needed:**
- 💰 **Cash Donations** - Money needed
- 🛠️ **Skills Needed** - Professional skills required
- 📦 **Items Needed** - Physical items required
- ⏰ **Time Needed** - Volunteer hours needed
- 🚚 **Transportation** - Delivery/logistics help
- 📱 **Tech Support** - IT/technical assistance

### **2. Enhanced Project Cards**
**Current:** Only "Cash 0%" and "Give" button
**Improved:** Show all contribution types with icons

### **3. Clear Call-to-Action Buttons**
**Instead of just "Give":**
- "Donate Money" 💰
- "Share Skills" 🛠️
- "Donate Items" 📦
- "Volunteer Time" ⏰
- "Help Transport" 🚚

### **4. Contribution Status Indicators**
**Show what's needed:**
- "Skills: 3/5 needed" 🛠️
- "Items: 2/10 collected" 📦
- "Volunteers: 5/8 needed" ⏰
- "Cash: $500/$2000 raised" 💰
